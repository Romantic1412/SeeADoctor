# 配置管理功能使用指南

## 功能概述

新增的配置管理功能允许你快速保存和加载抢号配置，方便在下次抢号时只需修改少量参数（如日期）即可开始。

## 使用方法

### 1. 保存配置

在**配置面板**（Config Panel）中：

1. 按正常流程配置好所有参数：
   - 选择医院、科室
   - 选择就诊人
   - 设置日期
   - （可选）选择医生和具体时段
   - 设置代理提交开关

2. 配置完成后，点击页面顶部**配置管理**区域的**"保存配置"**按钮

3. 系统将保存所有当前配置到本地文件 `config/user_state.json`

### 2. 加载配置

#### 在配置面板加载

1. 打开**配置面板**（Config Panel）
2. 点击顶部**配置管理**区域的**"加载配置"**按钮
3. 系统将从保存的配置文件恢复所有设置

#### 在主控台快速加载

1. 打开**主控台**（Dashboard）
2. 在**抢号控制**卡片中，点击配置状态旁边的刷新图标 🔄
3. 系统将快速加载已保存的配置

### 3. 快速修改日期进行下次抢号

这是本功能的主要使用场景：

1. 首次配置时：
   - 在配置面板完整配置所有参数
   - 点击"保存配置"保存设置

2. 下次抢号时：
   - 点击"加载配置"恢复所有设置
   - 只需修改**日期**字段为新的目标日期
   - 如需要，重新查询该日期的医生排班
   - 点击"保存配置"（可选）
   - 开始抢号

## 主控台配置显示

主控台的**抢号控制**卡片现在会显示完整的配置信息：

- **医院**：当前选择的医院名称
- **科室**：当前选择的科室名称
- **医生**：选择的医生名称（未选择则显示"不限"）
- **日期**：目标抢号日期
- **时段**：具体时段或时间类型（上午/下午）
- **代理提交**：是否启用代理提交

## 注意事项

- 配置保存在本地文件中，不会上传到服务器
- 每次点击"保存配置"会覆盖之前的配置
- 如果没有保存过配置，加载时会使用系统默认值
- 加载配置后，建议检查所有字段是否正确，特别是日期

## 技术说明

### 保存的配置字段

- `unit_id`, `unit_name`: 医院 ID 和名称
- `dep_id`, `dep_name`: 科室 ID 和名称
- `doctor_id`, `doctor_name`: 医生 ID 和名称（可选）
- `member_id`: 就诊人 ID
- `target_dates`: 目标日期列表
- `schedule_id`: 排班 ID（可选）
- `time_types`: 时间类型（如 am, pm）
- `preferred_hours`: 具体时段列表
- `proxy_submit_enabled`: 是否启用代理提交

### 配置文件位置

配置保存在 `config/user_state.json` 文件中。
